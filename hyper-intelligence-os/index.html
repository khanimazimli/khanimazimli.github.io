Case 03 · Independent initiative · 2026Working prototype, not in production

Hyper Intelligence OS

An independently initiated, AI-assisted campaign intelligence prototype.

One sentence in. A brief, a journey document, checked copy and a visual brief out, each waiting for a person to approve it. I identified the problem, own the product decisions, and built it by directing AI coding agents.

Problem
By my estimate, one campaign takes weeks across six stages owned by different teams, much of it restating the same facts.
My role
Initiated it on my own, own the product decisions, designed the workflow and built it with AI coding agents.
Why it was complex
Facts must stay identical from brief to copy, approvals in a bank must stay human, and image generation costs money.
Demonstrated
Three modules working, one in testing, on test campaigns. Not used on live campaigns.
01 What the prototype does

Four modules, each ending in a human decision.

Each module turns the previous approved output into the next draft. Rules handle facts and numbers; language models handle wording.

03 The problem it addresses

One offer. Six hand-offs. Six rewrites of the same facts.

Each stage turns the same offer into a new format for the next team. Every rewrite is a chance for a number to drift, and approvals only see the end result.

Limitations
  • Runs locally. Integration with the bank's marketing platform is proposed, not built.
  • Not used on live campaigns, and no time or cost savings have been measured.
  • Copy tone is not yet reliable enough to skip human review.
  • Built by directing AI coding agents and testing the result, not by writing production code by hand.

Options I compared, and how success would be measured
  • Process fixes onlyCheap, but people still restate the same facts at every step.
  • Automate end to end, approvals includedRemoves the controls the bank is accountable for.
  • A generic AI writing toolNo link between brief, scenario and copy, so numbers can drift.
  • Chosen: assist the four preparation stagesTargets where most time is assumed to go; facts are carried and checked across steps; every decision stays human.

A pilot would compare elapsed days per stage, review rounds before approval, number mismatches caught, and generation cost per campaign, with no change in the time or depth of Risk and Finance review.
